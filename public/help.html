Help Center

Find answers to common questions and get help using Etheroute

Getting Started

Visit the sign-up page, enter your desired username and password, and click "Create Account". No personal information is required. Your account will be ready to use immediately.

Once you've created an account and logged in, you can create wallets across multiple blockchain networks, view your portfolio, manage API keys, and initiate cryptocurrency withdrawals.

Wallets

Log in to your account, navigate to the Wallets section, and click "Add Wallet". Select your desired blockchain network (Ethereum, Bitcoin, Solana, or Litecoin), and a new wallet address will be generated for you automatically.

We currently support four major blockchain networks: Ethereum (ETH), Bitcoin (BTC), Solana (SOL), and Litecoin (LTC). You can create wallets on any of these networks.

Yes, you can create and manage multiple wallets across different blockchains. Each wallet is independently managed with its own balance and transaction history. You can organize them all from your dashboard.

In the Wallets section, find the wallet you want to delete and click the delete button. You'll be asked to confirm the deletion. Once deleted, the wallet cannot be recovered, so make sure to transfer any remaining funds first.

Transactions

The minimum withdrawal amount is $5 USD equivalent per transaction per blockchain network. This applies to each chain independently.

Most withdrawals are confirmed within 2 minutes. However, blockchain confirmation times may vary depending on network congestion and the specific blockchain you're using. You can track your withdrawal status in real-time in the Transactions section.

If a transaction fails, your funds will be returned to your wallet automatically. You can retry the transaction or contact our support team for assistance. Check the Transactions section for detailed status information.

Visit the Transactions section in your dashboard to see all past and pending transactions. You can view detailed information about each transaction including status, amount, blockchain, and timestamp.

Security & Account

Yes, we use bank-grade encryption and security protocols to protect your account. Your password is hashed using industry-standard algorithms and never stored in plain text. We maintain real-time monitoring and automated validations.

Yes, you can request account deletion through your account settings. When you delete your account, all associated data will be securely removed from our systems. This action is permanent.

Security features are constantly being enhanced. Check your account settings for the latest available security options to protect your account.

API & Developers

Log into your account and navigate to the API section in your dashboard. Click "Generate New Key" and your API key will be displayed securely. Store it safely and never share it publicly.

Complete API documentation is available at our API Reference page. It includes detailed endpoint descriptions, authentication methods, request/response examples, and error handling guidelines.

Yes, API rate limiting is enforced to ensure service stability for all users. Check the API Reference for specific rate limit details and best practices for your use case.

You can revoke API keys from the API section of your dashboard. Click the delete button next to the key you want to remove. Revoked keys will immediately stop working.
